# Django E-Learning Platform

A web-based E-Learning Platform built with Django that allows users to register, log in, enroll in courses, watch lessons, and manage their learning experience.

## Features

- User Registration & Login
- Course Management
- Course Enrollment
- Video-Based Lessons
- Student Dashboard
- Profile Management
- Password Reset Functionality
- Responsive Design

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap

## Security Features

- Password Hashing
- CSRF Protection
- SQL Injection Protection
- XSS Protection
- Session-Based Authentication

## CRUD Operations

- Create: Register Users, Enroll in Courses
- Read: View Courses and Lessons
- Update: Edit Profile and Reset Password
- Delete: Remove Courses or Enrollments

## Installation

```bash
git clone https://github.com/wajiharubab648-coder/eLearn-Django-LMS.git
cd eLearn-Django-LMS
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open your browser and visit:

http://127.0.0.1:8000/
